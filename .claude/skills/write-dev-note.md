# 写开发笔记 Skill

当用户要求写开发笔记（包括"写笔记"、"开发笔记"、"写总结"、"记录改动"等指令）时，自动执行：

## 规则

1. **文件名带日期** — 格式：`docs/YYYY-MM-DD-开发笔记.md`
2. **标题带时间** — 一级标题：`# YYYY-MM-DD 开发笔记`
3. **按模块分类** — 每个功能模块单独一个章节，用二/三级标题
4. **各点介绍** — 每个改动点用列表说明，写清楚改了什么、为什么改
5. **数据库变更汇总** — 如果有 ALTER TABLE，单独列出
6. **技术要点** — 涉及事务、并发、架构决策的要说明

## 内容结构

```
# YYYY-MM-DD 开发笔记

## 一、模块名称
### 1.1 功能点
- 改动说明

## 二、模块名称
...

## 数据库变更汇总
```sql
ALTER TABLE ...
```

## 技术要点
1. 要点说明
```

## 执行步骤

1. `git diff --stat` 和 `git status` 查看所有改动文件
2. 按模块分类改动（订单、出库、退货、快递、库存、商品、仓库、仪表盘等）
3. 读取关键文件理解改动内容
4. 按格式写入 `docs/YYYY-MM-DD-开发笔记.md`
5. 不要把此文件加入 git commit
