# 2026-06-17 Redis 缓存集成

## 背景

项目之前没有任何缓存，所有请求直接查库。仪表盘接口每次执行 50+ 条 SQL，JWT token 无法撤销，基础数据反复查库。

## 实现内容

### 1. 基础配置

- 添加 `spring-boot-starter-data-redis` 依赖
- 配置 `RedisConfig.java`：JSON 序列化（Jackson + JavaTimeModule）
- 封装 `CacheService.java`：get/set/delete/hasKey/getOrLoad 工具方法

### 2. 仪表盘缓存

- `ReportServiceImpl.getDashboard()` 缓存 5 分钟
- 缓存 key：`cache:dashboard`
- 命中缓存直接返回，未命中才执行 50+ 条 SQL

### 3. JWT 黑名单

- `JwtUtils` 新增 `getTokenRemainingTime()`、`getTokenBlacklistKey()`
- `JwtAuthFilter` 请求时检查 Redis 黑名单
- `UserController` 新增 `POST /api/auth/logout`，登出时写入黑名单
- 缓存 key：`jwt:blacklist:{token_hash}`，TTL = token 剩余有效期

### 4. 基础数据缓存

| 数据 | 缓存 Key | TTL | 清除时机 |
|------|----------|-----|----------|
| 平台列表 | `cache:platforms:enabled` | 30 分钟 | 平台增删改 |
| 快递公司 | `cache:express:companies` | 30 分钟 | 快递公司增删改 |
| 仓库详情 | `cache:warehouse:{id}` | 30 分钟 | 仓库增删改 |
| 分类树 | `cache:category:tree` | 30 分钟 | 分类增删改 |
| 角色列表 | `cache:roles:all` | 30 分钟 | 角色增删改 |
| 用户信息 | `cache:user:{id}` | 10 分钟 | 用户信息变更 |
| SKU 查询 | `cache:sku:code:{code}` | 10 分钟 | SKU 信息变更 |
| 快递查询 | `cache:express:query:{no}:{carrier}` | 30 分钟 | 自然过期 |

## 验证方式

```bash
# 连接 Redis 查看缓存 key
redis-cli
KEYS cache:*

# 查看缓存过期时间
TTL cache:dashboard
TTL cache:user:1

# 测试仪表盘缓存
# 第一次请求慢（查库），第二次快（缓存命中）
curl http://localhost:8080/api/reports/dashboard
```

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `REDIS_HOST` | `localhost` | Redis 地址 |
| `REDIS_PORT` | `6379` | Redis 端口 |
| `REDIS_DB` | `0` | 数据库编号 |
| `REDIS_PASSWORD` | 空 | 密码 |
