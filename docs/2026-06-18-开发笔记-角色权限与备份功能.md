# 2026-06-18 角色权限管理与备份功能

## 一、角色权限管理模块

### 背景

之前系统有角色但没有权限控制，所有用户都能访问所有功能。需要实现 RBAC，让管理员可以配置角色能访问哪些模块。

### 实现内容

#### 1. 后端

**新增文件：**
- `SysPermission.java` - 权限实体
- `SysRolePermission.java` - 角色权限关联实体
- `PermissionMapper.java` + `PermissionMapper.xml` - 权限 Mapper
- `RolePermissionMapper.java` + `RolePermissionMapper.xml` - 角色权限关联 Mapper
- `PermissionService.java` + `PermissionServiceImpl.java` - 权限服务
- `RoleService.java` + `RoleServiceImpl.java` - 角色服务（支持权限保存）
- `PermissionController.java` - 权限接口
- `RoleController.java` - 角色 CRUD 接口

**修改文件：**
- `RoleMapper.java` + `RoleMapper.xml` - 新增 insert/update/delete 方法
- `UserController.java` - 删除重复的 `/api/roles` 接口
- `PermissionServiceImpl.java` - 超级管理员强制拥有所有权限

#### 2. 前端

**新增文件：**
- `src/api/permission.ts` - 权限 API
- `src/views/system/RoleList.vue` - 角色管理页面（含权限树配置）

**修改文件：**
- `src/router/index.ts` - 新增角色管理路由
- `src/utils/constants.ts` - 菜单项增加 permission 字段
- `src/stores/user.ts` - 新增 permissions 存储和 hasPermission 方法
- `src/layouts/DefaultLayout.vue` - 菜单根据权限动态过滤

#### 3. 权限数据

基于现有菜单结构，共 27 个权限编码：
```
dashboard, ai.assistant, ai.knowledge
warehouse.list, warehouse.shelf, warehouse.special
product.list, product.sku
stock.query, stock.log, stock.check
order.list, outbound.list, returns.list, exchange.list
express.query, express.company, express.template, express.report
system.users, system.roles, system.files, system.logs
system.stock-alert, system.stock-alert-template, system.platforms, system.backup
```

#### 4. 特殊逻辑

- 超级管理员（SUPER_ADMIN）强制拥有所有权限，不受角色配置限制
- 角色管理页面隐藏超级管理员角色
- 登录后自动获取权限列表，菜单动态过滤

### 使用方式

1. 执行 `wms-backend/sql/permission-seed.sql` 初始化权限数据
2. 以 SUPER_ADMIN 登录，进入"系统管理 → 角色管理"
3. 创建新角色，勾选可访问的权限模块
4. 创建用户分配该角色
5. 以该用户登录，只能看到被授权的菜单

## 二、自动备份与远程备份

### 背景

数据库备份需要手动操作，且只能保存在本地。需要支持定时自动备份和上传到远程服务器。

### 实现内容

#### 1. 自动备份

- 使用 Spring `@Scheduled` 定时任务
- 支持配置 cron 表达式（每天凌晨 2:00 / 3:00 / 12:00 等）
- 可选全量备份或增量备份
- 默认关闭，需在备份设置中开启

#### 2. 远程备份

- 使用 SCP 协议上传备份文件到远程服务器
- 支持配置远程主机、SSH 端口、用户名、密码、路径
- 提供测试连接功能
- 自动备份时如果启用了远程备份，会自动上传

#### 3. 新增文件

**后端：**
- `BackupConfig.java` - 备份配置实体
- `BackupConfigMapper.java` + `BackupConfigMapper.xml` - 配置 Mapper
- `BackupScheduler.java` - 定时任务调度器
- `RemoteBackupService.java` - 远程备份服务（SCP）
- `backup-config-table.sql` - 配置表 SQL

**前端：**
- `backup.ts` - 新增配置 API（getBackupConfig, saveBackupConfig, testRemoteConnection）
- `BackupManage.vue` - 新增"备份设置"按钮和配置弹窗

#### 4. 新增接口

| 接口 | 说明 |
|------|------|
| `GET /api/backup/config` | 获取备份配置 |
| `POST /api/backup/config` | 保存备份配置 |
| `POST /api/backup/config/test-remote` | 测试远程连接 |

### 使用方式

1. 执行 `wms-backend/sql/backup-config-table.sql` 创建配置表
2. 进入"系统管理 → 数据库备份"
3. 点击"备份设置"按钮
4. 开启自动备份，选择备份类型和时间
5. 如需远程备份，开启并配置远程服务器信息
6. 点击"测试连接"验证配置
7. 保存配置

### 注意事项

- 远程备份依赖服务器上的 `scp` 命令
- 如需密码认证，需安装 `sshpass`
- 建议使用 SSH 密钥认证更安全
