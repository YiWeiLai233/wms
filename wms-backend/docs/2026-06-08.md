## 技术笔记

- Spring Boot 4.0.6 + Spring Security 采用 Lambda DSL 配置方式
- JWT 使用 jjwt 0.12.6，`Jwts.parser()` 已改为 `Jwts.parser().verifyWith()`
- MyBatis MapperScan 路径：`com.yiweilai.wms.**.mapper`（支持多模块）
- BCrypt 加密密码存储，登录时用 `passwordEncoder.matches()` 校验
